Cara menambah channel IPC baru:
1. Buat file handler di src/main/ipc/<domain>/ipc/my-handler.ts (ipcMain.handle('my:channel', …))
2. Daftarkan di src/main/ipc/<domain>/register-handlers.ts
3. Ekspos di src/preload/api/ via ipcRenderer.invoke('my:channel', …)
4. Tambah ke window.api di src/preload/index.ts
