# UI Inspo & Design

Reference material for the desktop app and the web replay. **Guidelines only.**

| Folder | Contents |
|---|---|
| `UI Inspo/` | Inspiration screenshots (Orca, Amoeba, Mosaic) |
| `UI Design/` | Stitch mockups of the Live Collab screens |
| `landing-style/` | "Warm paper" direction for the landing page (DESIGN.md §5.11) |

Rules:
- The app follows **Orca's look first** (dark, Orca tokens and fonts). Live Collab only adds accents on top (DESIGN.md §0, D-006 point 6).
- Stitch mockups are a starting point, not a spec. Never ship numbers or data invented by a mockup.
- The replay page is dark like the app. The landing page is light "warm paper".
- Do not commit videos larger than 10 MB here.
